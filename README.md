## Dashboard Comercial

O projeto conta com um dashboard desenvolvido no Power BI, dividido em três páginas, com o objetivo de transformar os dados transacionais da LojaVarejoDB em indicadores e análises de negócio.

### Página 1 — Visão Geral

Apresenta os principais indicadores de desempenho comercial da empresa, permitindo uma visão rápida do faturamento, volume de pedidos, ticket médio e quantidade de clientes.

Principais análises:
- Receita total
- Quantidade de pedidos
- Ticket médio
- Clientes únicos
- Evolução mensal da receita
- Receita por canal
- Receita por estado

## Principais Insights

A análise do dashboard permitiu identificar alguns pontos relevantes sobre o desempenho da empresa:

- O site apresentou a maior participação na receita entre os canais analisados.
- Minas Gerais foi o estado com maior receita no período.
- Algumas categorias apresentaram maior contribuição para o faturamento, enquanto outras se destacaram pela margem.
- O ranking de produtos permitiu identificar os itens com maior impacto financeiro.
- A análise de clientes mostrou uma alta concentração de clientes recorrentes na base.

## Processo do Projeto

1. Modelagem e estruturação do banco de dados no SQL Server.
2. Exploração e análise dos dados utilizando SQL.
3. Criação das métricas necessárias para análise.
4. Conexão do banco de dados ao Power BI.
5. Criação das medidas utilizando DAX.
6. Desenvolvimento do dashboard.
7. Análise dos resultados e identificação de insights.
